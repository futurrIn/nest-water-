## Phased Execution Workflow

### Phase 1: Assets Preparation
- Extract logo emblem and craft `assets/logo.svg` and `assets/favicon.svg`.
- Extract or generate high quality images for `hero-purifier.png`, `water-filter.jpg`, `industrial.jpg`, and `water-bg.jpg`.

### Phase 2: HTML Core & Semantic SEO Structure
- Construct `index.html` with semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Implement SEO title: `Water Purifiers & Water Treatment Solutions in Kerala | NEST Water Technologies`.
- Implement SEO H1: `Water Purifiers & Water Treatment Solutions in Kerala`.
- Embed LocalBusiness `JSON-LD` structured data.

### Phase 3: CSS Styling & Responsive Design System
- Establish CSS Custom Properties for near-black navy backgrounds, glassmorphism, electric blue glows, and typography.
- Desktop layout (1200-1400px container) matching desktop design reference.
- Mobile layout (320px-480px) matching mobile design reference with smooth navigation drawer and bottom sticky quick-call bar.

### Phase 4: Interactivity & JS Mechanics
- Implement glass navbar transition on scroll.
- Mobile hamburger menu animation and drawer control.
- Smooth scrolling for internal anchor links.
- Interactive modal / toast for contact form submissions.

### Phase 5: Verification & Quality Assurance
- Test local server preview.
- Ensure zero horizontal scrolling on mobile viewports.
- Check accessibility, WCAG contrast, aria attributes, and button touch targets.
